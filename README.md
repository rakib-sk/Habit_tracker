# 📝 Habit Tracker (HTML + CSS)

A clean and minimal **Habit Tracker Web App** designed using **HTML & CSS**.  
This project helps users track daily habits visually using progress bars, habit cards, and status summary.  
JavaScript functionality (add, delete, progress update, streak calculation) can be added later.

---

## 🚀 Features (Current)

### ✔️ 1. Add New Habit (UI Only)
- Input box for entering a new habit  
- Styled “Add Habit” button  
- Smooth UI structure for future JS integration

### ✔️ 2. Habit List Section
- Each habit card shows:
  - Habit title  
  - Progress bar  
  - Percentage text  
  - “Done Today” button  
  - “Delete” button  
- Beautiful modern UI using shadows, borders, and spacing

### ✔️ 3. Status Overview
- Shows:
  - Total habits  
  - Completed today  
  - Best streak  
- Nicely organized using flexbox layout
